# AGENTS.md — TestingSite1
## Ce este proiectulSite personal de prezentare, o singură pagină, static.Tehnologii: HTML, CSS și JavaScript simplu. Fără framework, fără build step,fără dependențe npm. Se publică automat pe GitHub Pages din ramura `main`.
- Repository: https://github.com/mapostol21/TestingSite1- Site live: https://mapostol21.github.io/TestingSite1/
## Structura fișierelor- `index.html` — singura pagină. Conține header, hero, Despre, Proiecte, Contact, footer.- `style.css` — toate stilurile. Folosește variabile CSS definite în `:root`.- `script.js` — interactivitate: anul curent în footer, butonul de temă.- `assets/` — imagini (se creează când e nevoie).
## Cum se lucrează- Previzualizare locală: extensia Live Server din VS Code, click dreapta pe `index.html`.- Publicare: `git add .` → `git commit -m "mesaj"` → `git push`. Site-ul se actualizează în 1–2 minute.- După orice modificare făcută direct pe GitHub, rulez `git pull` înainte de a lucra local.
## Reguli- Nu introduce framework-uri, bundler-e sau dependențe externe fără să mă întrebi.- CSS scris manual. Fără Tailwind, fără Bootstrap.- Nu folosi CDN-uri pentru fonturi sau iconițe; doar resurse locale sau emoji.- Toate textele vizibile pentru utilizator sunt în română, cu diacritice corecte.- În cod (nume de clase, id-uri, variabile, fișiere) folosește DOAR caractere ASCII:  fără diacritice. Clasa de temă închisă se numește `dark`, nu `întunecat`.- Fiecare modificare = un commit mic, cu mesaj la prezent: „Adăugat secțiunea contact".- Nu șterge și nu redenumi fișierele existente fără confirmare.- Nu adăuga comentarii inutile în cod; codul trebuie să se explice singur.
## Stil vizual- Fundal alb în tema deschisă (#ffffff), text închis (#1a1a2e).- Tema închisă: fundal #14161c, text #e8eaf0. Se activează prin clasa `dark` pe elementul `<html>`.- Un singur accent de culoare: #2d6cdf.- Font: `system-ui, -apple-system, sans-serif`. Fără webfonturi.- Lățime maximă a conținutului: 720px, centrat.- Design responsive; breakpoint la 600px.
## Decizii deja luate- Hosting: GitHub Pages, gratuit, din ramura `main`, folder `/ (root)`.- Fără formulare de contact deocamdată. Când va fi nevoie: Formspree.- Fără analytics.- Tema aleasă de utilizator NU se salvează încă între reîncărcări (de implementat cu localStorage).
